# Sending pages

Use the Notekeeper web tool (Export for TI-84 CE) or tools/nkpack.py to make the files, then send NKIDX.8xv and every NKP*.8xv / NKI*.8xv file with TI Connect CE.

The page list is read from the NKIDX appvar. Edited pages are saved back as ordinary appvars, so they survive until you delete them or reset RAM.

Archive the files you do not edit to keep RAM free. Pictures are only read, never copied, so they can stay in the archive.
